## Section 1: Your setup today

**FAC:** What do you change or turn on when you start using a new app or website?

**P1:** Honestly, first I figure out if it works with my screen reader at all. Then I go hunting for the headings. If the headings are a mess I usually give up.

**P2:** Zoom. Always zoom. Then I find out the menu has disappeared off the side of the screen, and I zoom back out, and then I can't read it. Every single site.

**P3 (chat):** captions on, autoplay off. and i have to find where they hid the setting every time

**P4:** I use voice control, so the first thing is whether the buttons have names I can actually say. A lot of them are just icons. I end up saying "show numbers" and picking number 47 or whatever.

**P5:** Bigger text, and I turn off anything that moves. Moving things make it really hard for me to keep my place.

**FAC:** What do you wish you didn't have to set up again every time?

**P5:** All of it! I set it up on my laptop, then my phone is completely different, then my daughter's tablet.

**P2:** Same. I make the text bigger on every site, every single time.

**P3 (chat):** captions. i've turned on captions probably ten thousand times in my life

## Section 2: Ability profile

**FAC:** If an app could remember one thing about how you like to use it, what would it be?

**P1:** That I'm using a screen reader, so it should give me the structured version, not the pretty version.

**P4:** Not that I have a disability. Just that I use voice. Those are different things.

**FAC:** Is there anything you'd never want an app to remember or share?

**P4:** Anything that sounds like a diagnosis. I don't want an insurance company or an employer seeing that I use these tools and guessing why.

**P2:** I'd want to see the list of what it remembered. In plain words. And delete things.

**P3 (private message to FAC):** i'd want to be able to have one profile for work and one for home. my work doesn't need to know everything.

**FAC:** Who should hold this information?

**P1:** Me. Or at least, I should be able to take it with me if I leave.

**P5:** I don't really understand where it would be kept. I'd need someone to explain that to me simply before I said yes.

**Private response round** ("I'd be comfortable with my preferences following me from one app to the next"):
Green: P1, P5 · Yellow: P2, P4 · Red: P3 (private: "only if i choose which apps")

## Section 3: Adapter

*FAC demonstrated three adaptations on a test news page using the example browser extension: larger text, charts as tables, and reduced motion.*

**P2:** The larger text was good, but the menu still went under the article. Same problem as always, just automatic now.

**P1:** Charts as tables, yes. That's the first time a chart has actually told me anything. But it didn't tell me the table was there. I found it by accident.

**P5:** The motion one was lovely. Everything just stopped jumping. Can it do that everywhere?

**P4:** I tried the page with voice. The new table had no name, so I couldn't jump to it by saying anything.

**FAC:** Should changes happen automatically, be suggested, or only when you ask?

**P5:** Suggested, the first time. Then automatic once I've said yes.

**P1:** Automatic, but tell me what you changed. Out loud, briefly.

**P2:** Suggested, always. I've been burned by things that "helped."

**Private response round** (per adaptation):
Larger text: Green P5 · Yellow P2 ("menu still breaks"), P4 · Not tried P1, P3
Charts as tables: Green P1, P2, P3 · Yellow P4 ("can't navigate to it by voice")
Reduced motion: Green P2, P3, P4, P5 · Not relevant P1

## Section 4: Validation

**FAC:** You've asked an AI assistant to renew a subscription. It finds a cheaper plan that removes a feature you use. What should it do?

**P4:** Stop. Obviously stop. Anything involving money, stop.

**P1:** Stop, and tell me what the difference is in a way I can actually get through. Not a giant comparison table.

**P3 (chat):** stop and send me a message. don't call me, don't use a sound. a message i can read when i'm ready

**P5:** I'd want it to wait for me. Sometimes I need a bit longer to think. Don't time out on me.

**FAC:** Has a tool ever made a decision for you that you wish it had asked about first?

**P2:** A screen reader update changed all my settings once. Took me a week to get back to normal.

**P5:** My phone "simplified" my home screen once. I couldn't find anything for days.

---

## Section 5: What's missing

**P1:** Tell me when something has been changed. Every time.

**P5:** An undo button. A big obvious one.

**P3 (private form, after session):** the setup should work without audio or video. i couldn't follow the demo part properly because the captions lagged behind the screen.
